ТРЕВОГА UA — карта воздушных тревог Украины

Сайт: https://trevoga-ua.onrender.com
Репозиторий: https://github.com/dxd89293-ux/trevoga-ua

ВОЗМОЖНОСТИ
- Карта областей Украины и список региональных статусов.
- Два открытых агрегатора данных: NEPTUN и Tryvoha.online.
- Автоматическая проверка примерно раз в минуту и повторная проверка при возвращении на вкладку.
- Отдельные состояния: тревога, отбой, нет данных и расхождение источников.
- При расхождении источников регион не считается подтверждённой тревогой или отбоем.
- Красный/жёлтый уровень показывается только при наличии соответствующего поля в данных.
- Сводка по регионам, источникам и времени проверки.
- Звук, вибрация, уведомления браузера и выбор областей.
- PWA-установка, офлайн-оболочка и обработчики Web Push.
- История переходов статуса и статистика за текущий день.

ИСТОРИЯ И ОГРАНИЧЕНИЯ
- Общая история хранится в Cloudflare KV и пополняется только после подтверждённых переходов, когда оба API доступны, Tryvoha имеет свежую метку времени, а статусы источников совпадают.
- История начинается с момента включения соответствующего кода Worker; старые события задним числом не восстанавливаются.
- Локальная история — запасной вариант на одном устройстве. Она фиксирует изменения только пока сайт открыт и не является полной статистикой.
- Если Worker ещё не обновлён, общая история недоступна; сайт покажет локальные записи.
- Продолжительность тревоги показывается только при наличии времени начала в ответе источника. Иначе выводится, что время начала не указано.
- NEPTUN и Tryvoha.online — агрегаторы; они могут использовать общие первичные данные. Их совпадение не гарантирует независимое подтверждение.

PUSH
- Push при закрытом сайте выполняется отдельным Cloudflare Worker, а не статическим сайтом Render.
- Региональные фильтры и история на сервере требуют актуальной версии Worker.
- Cloudflare Worker — отдельный сервис: деплой Render/GitHub Pages его не обновляет. Если для Worker подключён Cloudflare Workers Builds, коммит в main запускает его отдельную сборку/публикацию; иначе нужен npm run deploy из push-server.
- VAPID private key хранится только в Cloudflare Secrets. Не добавляй его в GitHub, push-config.js или сообщения.
- Доставка push зависит от браузера, разрешений, Android, сети и состояния устройства; она не гарантируется.

БЕЗОПАСНОСТЬ
Карта является дополнительным информационным источником, а не системой экстренного оповещения. Не используй её для решения, идти ли в укрытие. Официальные сирены, государственные приложения/каналы оповещения и указания экстренных служб имеют приоритет. При тревоге следуй официальным инструкциям и переходи в укрытие.

ДЕПЛОЙ
Render автоматически публикует изменения статического сайта из ветки main. Cloudflare Worker требует отдельного deploy.
