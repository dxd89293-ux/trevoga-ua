ТРЕВОГА UA — карта воздушных тревог Украины

Сайт: https://trevoga-ua.onrender.com
Репозиторий: https://github.com/dxd89293-ux/trevoga-ua

ТЕКУЩИЕ ВОЗМОЖНОСТИ
- Карта областей Украины и список региональных статусов.
- Два открытых агрегатора данных: NEPTUN и Tryvoha.online.
- Автоматическое обновление данных примерно раз в минуту.
- Серый статус «НЕТ ДАННЫХ», если подтверждённой информации нет.
- Отдельная индикация возможного расхождения источников.
- Тёмная карта, подписи городов и областей.
- Звуковой сигнал, вибрация и уведомления браузера при изменении статуса (после включения пользователем; пока сайт открыт).
- Проверка звука и установка сайта как PWA на поддерживаемых браузерах.
- Service Worker с офлайн-оболочкой и обработчиками входящих Web Push-событий.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
1. Push-уведомления при полностью закрытом сайте пока НЕ активированы: для этого необходим отдельный сервер Web Push, VAPID-ключи, безопасное хранение подписок и регулярная проверка источников.
2. Сам обработчик push в service worker не отправляет уведомления. Он только принимает их от настроенного сервера.
3. Звук, вибрация и обычные уведомления браузера могут ограничиваться Android/браузером в фоне.
4. Данные двух агрегаторов могут происходить из общих первичных источников; совпадение не является независимым подтверждением.
5. Карта не прогнозирует маршруты БПЛА или ракет и не должна использоваться для определения безопасного направления или времени.
6. В репозитории подготовлен отдельный Cloudflare Worker для push при закрытом сайте; он не активен, пока не создан KV namespace, не добавлены VAPID-секреты и не выполнен deploy. Инструкция: `push-server/README.md`.

ИСТОЧНИКИ И ПРЕДУПРЕЖДЕНИЕ
Данные берутся из открытых API NEPTUN и Tryvoha.online. Если источники недоступны, данные устарели или регион нельзя надёжно сопоставить, приложение показывает отсутствие данных, а не выдумывает статус.
Карта — только дополнительный информационный источник. Официальные сирены, приложение/каналы оповещения и указания экстренных служб имеют приоритет. При тревоге следуй официальным инструкциям и переходи в укрытие.

УСТАНОВКА НА ANDROID
1. Открой сайт в Chrome.
2. Если появилась кнопка «Установить приложение», нажми её; либо открой меню ⋮ и выбери «Установить приложение» / «Добавить на главный экран».
3. Для звука и уведомлений нажми «Включить звук и уведомления» и выдай разрешение браузеру.

ДЕПЛОЙ
Render Static Site автоматически публикует изменения из ветки main после коммита в GitHub. Push-бэкенд требует отдельного развёртывания и настройки; текущий Render Static Site его не запускает.
