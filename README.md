# Тревога UA

Информационная карта воздушных тревог по регионам Украины.

- Сайт: https://trevoga-ua.onrender.com
- Источники: NEPTUN и Tryvoha.online
- Статический сайт автоматически публикуется из ветки `main`.
- Отдельный Cloudflare Worker находится в `push-server/` и требует собственного deploy.

## Возможности

Карта и список статусов регионов, сводка, проверка доступности источников, уровни тревоги из API, настройки звука/вибрации/браузерных уведомлений, региональные предпочтения push, PWA и офлайн-оболочка. При отсутствии данных или расхождении источников приложение не должно показывать подтверждённый отбой.

История переходов статуса хранится на сервере в Cloudflare KV после развёртывания актуальной версии Worker. Локальная история — только резервный журнал изменений, замеченных в открытой вкладке на конкретном устройстве. История не восстанавливается задним числом.

## Разработка и публикация

Подробная инструкция по Cloudflare Worker, KV и VAPID находится в [push-server/README.md](push-server/README.md). После изменения файлов Worker необходим отдельный `npm run deploy` из папки `push-server`; деплой статического сайта Worker не обновляет.

## Важное предупреждение

Это дополнительный информационный источник, не официальная система экстренного оповещения. Источники могут быть недоступны, устаревать или использовать общие первичные данные. Следуй сиренам и официальным указаниям служб, а при тревоге переходи в укрытие.
